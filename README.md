# jazzchords

[https://jazzchords.singingtrumpet.com/](https://jazzchords.singingtrumpet.com/)

A tool for learning jazz chords.

Designed primarily for a mobile phone (iPhone XS as a reference). 

On a desktop use `tab`, `space`/`enter` and `arrow` keys to navigate. Browsers tested (on macOS): Chrome, Safari, Opera and Firefox.

This program is a progressive web app that can be installed on mobile devices.

Written with React, Typescript & SCSS. Set up with Vite.

More docs in [md folder](https://github.com/visahaarala/jazzchords/tree/main/md).
